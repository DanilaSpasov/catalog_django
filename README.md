# Catalog Django Project

**catalog_django** — Django-проект, в котором реализовано веб-приложение с каталогом товаров и блогом. Проект включает работу с базой данных PostgreSQL, использование Class-Based Views (CBV), полноценный CRUD для товаров и блоговых записей, административную панель, а также инструменты для наполнения базы данных тестовыми данными.

---

# Технологии и стек

* **Фреймворк:** Django 6
* **Язык программирования:** Python 3
* **СУБД:** PostgreSQL
* **ORM:** Django ORM
* **Шаблоны:** Django Templates + Bootstrap 5
* **Контроль версий:** Git / GitHub
* **Аутентификация:** Django Authentication System
* **Пользовательская модель:** AbstractUser
* **Отправка email:** Django Email Backend

---

# База данных

Проект использует PostgreSQL.

Настройки подключения задаются в файле `settings.py` через переменные окружения.

Для работы необходимо:

1. установить зависимости проекта;
2. создать файл `.env` по примеру `.env_example`;
3. заполнить параметры подключения к базе данных и `SECRET_KEY`.


---

# Структура проекта

Проект состоит из трех приложений:

* **catalog** — каталог товаров;
* **blog** — блог с поддержкой публикации статей.
* **users** — приложение для работы с пользователями и аутентификацией.

---

# Функциональность

## Каталог товаров

Реализовано:

- Отображение списка товаров 
- Страница детального просмотра товара 
- Отображение изображения, цены и описания 
- Связь товаров с категориями
- Полный CRUD для товаров
- Создание товара через Django Forms
- Редактирование товара
- Удаление товара
- Валидация названия и описания на наличие запрещённых слов
- Проверка цены на отрицательное значение
- Стилизация форм с использованием Bootstrap 5
---

## Блог

Для приложения `blog` реализован полный CRUD.

Возможности:

* просмотр списка статей;
* просмотр отдельной статьи;
* создание статьи;
* редактирование статьи;
* удаление статьи;
* загрузка изображения;
* отображение количества просмотров;
* отображение только опубликованных статей;
* автоматическое увеличение количества просмотров;
* после редактирования пользователь перенаправляется обратно на страницу статьи.

---

# Пользователи и аутентификация

Для работы с пользователями создано отдельное приложение `users`.

Реализована собственная модель пользователя на основе `AbstractUser`.

Возможности:

- регистрация пользователя по электронной почте;
- авторизация по электронной почте и паролю;
- отправка приветственного письма после регистрации;
- хранение дополнительной информации о пользователе.

Дополнительные поля пользователя:

- `avatar` — изображение профиля;
- `phone` — номер телефона;
- `country` — страна пользователя.

В качестве основного поля авторизации используется электронная почта.

---

## Ограничение доступа

Для страниц управления товарами реализована проверка аутентификации пользователя.

Доступ разрешен только авторизованным пользователям:

- создание товара;
- редактирование товара;
- удаление товара.

Страница просмотра списка товаров остается доступной всем пользователям.

Для ограничения доступа используется `LoginRequiredMixin`.

# Модели

## Category

Поля:

* `title` — название категории;
* `description` — описание категории.

---

## Product

Поля:

* `name` — название товара;
* `description` — описание;
* `image` — изображение;
* `category` — категория (`ForeignKey`);
* `price` — стоимость;
* `created_at` — дата создания;
* `updated_at` — дата изменения.

---

## Blog

Поля:

* `title` — заголовок;
* `content` — содержимое статьи;
* `preview_image` — изображение статьи;
* `created_at` — дата создания;
* `is_published` — признак публикации;
* `views_count` — количество просмотров.

---

## User

Пользовательская модель создана на основе `AbstractUser`.

Поля:

* `email` — электронная почта пользователя (используется для авторизации);
* `password` — пароль пользователя;
* `avatar` — изображение профиля;
* `phone` — номер телефона;
* `country` — страна пользователя.

# Дополнительная логика

Для приложения блога реализованы следующие возможности:

### Увеличение количества просмотров

При открытии страницы статьи автоматически увеличивается счетчик просмотров.

Реализовано переопределением метода:

```
get_object()
```

---

### Фильтрация статей

На странице списка отображаются только опубликованные статьи.

Используется переопределение:

```
get_queryset()
```

---

### Перенаправление после редактирования

После успешного редактирования пользователь автоматически перенаправляется на страницу просмотренной статьи.

Используется:

```
get_success_url()
```

## Для каталога товаров

### Валидация формы

Для формы создания и редактирования товаров реализована собственная валидация (`ProductForm`).

Проверяется:

* отсутствие запрещённых слов в названии и описании товара (без учёта регистра);
* корректность стоимости товара — цена не может быть отрицательной.

# Административная панель

В административной панели зарегистрированы модели:

* Category;
* Product;
* Blog;
* User.

Для моделей настроены:

* отображаемые поля (`list_display`);
* ссылки на объекты (`list_display_links`);
* поиск (`search_fields`);
* фильтрация (`list_filter`).

Для модели пользователя отображаются:

* электронная почта;
* имя и фамилия;
* статус сотрудника;
* статус активности пользователя.

# Аутентификация

Для работы с пользователями реализованы:

## Регистрация

Пользователь может создать учетную запись, указав:

- электронную почту;
- пароль.

После успешной регистрации пользователю отправляется приветственное письмо.

## Авторизация

Вход в систему осуществляется по:

- электронной почте;
- паролю.

После входа пользователь получает доступ к функциям управления товарами.

# Доступные страницы

После запуска проекта доступны маршруты:
* /home/ - главная страница 
* /contacts/ -страница контактов 
* /admin/ - панель администратора Django
* product/<id>/ - страница товара
* /blog/ - список статей
* /blog/<id>/ - просмотр статьи
* /blog/create/ - создание статьи
* /blog/<id>/update/ - редактирование статьи
* /blog/<id>/delete/ - удаление статьи
* /users/register/ - регистрация пользователя
* /users/login/ - авторизация пользователя
* /users/logout/ - выход из аккаунта
